ПОДХОД — первая версия

Размещение: создайте публичный репозиторий GitHub, загрузите index.html, sw.js, manifest.webmanifest и icon.svg в корень. В Settings → Pages выберите Deploy from a branch, main, / (root). Откройте выданный адрес в Safari и добавьте на экран Домой. Это статическое приложение, серверная база не нужна.

План — черновой сокращённый вариант из обсуждения, ещё не окончательно согласованный. Сведение ног предварительное. Подходы: недели 1–2 изоляция 2 / основные 3; недели 3–4 3/3; недели 5–6 3/4; недели 7–8 4/4. Недели считаются от выбранной даты начала. После восьмой недели приложение остаётся на последнем этапе, новый цикл автоматически не запускает. Разминочные подходы отдельно не учитываются.

Двойная прогрессия: все подходы выполнены с одинаковым положительным весом и верхней границей повторов или выше; задан шаг прибавки. Следующая запись предлагает прибавку, кроме случая увеличения числа подходов. Веса и повторы всегда можно исправить. Укажи шаг до завершения тренировки. Веса EZ вводятся суммарно с грифом. Большинство неизвестных весов оставлены пустыми; для новых диапазонов подбери рабочую нагрузку.

Локальные данные сохраняются в хранилище браузера этого адреса. Синхронизации и серверного резервирования нет. Очистка данных сайта, смена адреса, режима запуска или устройства может сделать старые записи недоступными. Регулярно делай экспорт; импорт заменяет данные. Файл резервной копии содержит историю и текущую тренировку. Импортируй только собственные копии.

Таймер использует абсолютное время: после возвращения показывает оставшийся отдых. При блокировке экрана или сворачивании iOS может приостановить страницу и звук: гарантированного фонового сигнала и push-уведомлений нет. Звук работает по возможности, пока приложение открыто. Офлайн доступен после первого успешного онлайн-открытия и установки service worker; проверь авиарежимом до зала.

Версия не тестировалась на физическом iPhone. Для запуска локально нужен HTTP-сервер, не открытие файла из Файлов.
